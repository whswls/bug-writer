QA Toolkit 사용 가이드

지라 버그 등록 · 이슈 확인 코멘트 · 일일보고를 형식에 맞게 자동으로 만들어주는 도구예요. 상단 탭으로 모드를 전환해서 쓰면 돼요.

1. 버그 등록

  • 제목 — 구분(통합앱/MW/PC)과 플랫폼을 버튼으로 고르면 발생 범위 선택지가 자동으로 바뀌고, 제목이 팀 규칙에 맞게 조합돼요.
  • Android·iOS 둘 다 발생하면 각각 별도 이슈로 등록하라는 안내가 떠요.
  • 발생 기기 — 특정 기기에서만 발생할 때 선택하면 참고사항에 자동으로 들어가요.
  • Description — 재현경로는 엔터 시 번호(1. 2. 3.)가, 참고사항은 하이픈(-)이 자동으로 붙어요. URL을 붙여넣고 버튼을 누르면 디버그 파라미터도 자동 추가돼요.
  • 다 쓰면 오른쪽 전체 복사 → 상단 + 버그 등록으로 지라를 열어 붙여넣으면 끝이에요.

2. 이슈 확인

  • 구분·서버·결과를 고르고 확인 내용만 쓰면 코멘트 형식이 완성돼요. 서버는 여러 개 선택할 수 있어요.
  • 버전은 한 번 입력하고 기본값으로 저장해두면 다음부터 자동으로 채워져요.
  • MW·통합앱을 모두 확인했다면 확인 블록 추가로 환경별 내용을 이어서 작성할 수 있어요.

3. 일일보고

  • 항목별로 건수·시간·상세 내용을 채우면 표로 정리돼요. 시간은 숫자만 적으면 H가 자동으로 붙어요.
  • 이슈 관련 항목은 건수가 자동 계산돼요. 오늘 등록한 이슈 버튼으로 지라 목록을 열어 복사한 뒤 이슈키만 정리를 누르면 이슈 번호만 깔끔하게 남아요.
  • 보고 내용 복사 후 엑셀·구글시트에 붙여넣으면 칸이 나뉘어 들어가요.

4. 커스텀 블록 (자주 쓰는 문구 버튼)

참고사항이나 일일보고 기타처럼 매번 비슷한 내용을 쓰는 칸에는, 한 번 클릭으로 문구가 들어가는 블록 버튼이 있어요.

  • 추가하기 — ✎ 문구 편집을 누르고 한 줄에 하나씩 적은 뒤 적용을 누르면 버튼이 생겨요.
  • 참고사항은 라벨 | 삽입할 문구 형식이에요. 왼쪽이 버튼에 보일 이름, 오른쪽이 실제로 들어갈 문구예요. | 없이 한 줄만 적으면 그 문장이 버튼 이름이자 문구가 돼요.
  • 일일보고 기타는 그냥 문구만 한 줄씩 적으면 돼요.
  • 삭제하기 — 버튼 옆의 ✕를 누르면 그 문구만 지워져요.
  • 하이픈(-)은 자동으로 붙으니 직접 안 적어도 돼요.
  • 다른 섹션에도 이 버튼을 달고 싶으면 ⚙ 섹션 설정에서 그 섹션의 빠른문구를 체크하면 돼요.

5. 섹션 · 항목 직접 바꾸기

  • 섹션 이름·순서 — ⚙ 섹션 설정에서 이름을 바꾸거나 ↑↓로 순서를 옮기고, ✕로 삭제할 수 있어요.
  • URL도우미를 켜면 그 섹션에 URL 입력칸이 생기고 엔터 시 번호가 자동으로 매겨져요. 빠른문구는 블록 버튼과 하이픈 자동 입력, 넓게는 입력칸을 크게 열어줘요.
  • 결과 옵션, 보고 항목, 팀 기기 목록도 각 ✎ 편집 버튼으로 바꿀 수 있어요.

6. 설정 저장과 공유 중요

적용 누르는 즉시 이 브라우저에 자동 저장돼요. 파일을 닫았다 열어도, PC를 재부팅해도 그대로 유지돼요. 평소엔 이것만 누르면 충분해요.
파일로 내보내기 설정이 담긴 HTML 파일을 다운로드해요. ① 팀원에게 공유할 때 ② 다른 PC·브라우저에서 쓸 때 ③ 백업이 필요할 때 — 이 세 경우에만 쓰면 돼요.

한 줄 요약: 평소엔 적용만, 공유·백업할 때만 내보내기.

7. 할 일 · 일정 백업 중요

왜 필요한가요? 할 일·일정·연차는 설정과 마찬가지로 이 브라우저 안에만 저장돼요. 브라우저 캐시(인터넷 사용 기록)를 지우거나 다른 PC에서 열면 보이지 않아요. 설정은 다시 만들면 되지만 기록해둔 할 일은 되살릴 수 없어요.
어떻게 하나요? 할 일·일정 탭 아래쪽 내 데이터 백업에서 백업 파일 저장을 누르면 파일 하나가 다운로드돼요. 그 파일을 회사 구글 드라이브·원드라이브처럼 동기화되는 폴더에 두세요. 나중에 백업 파일 불러오기로 그대로 복원돼요.
  • 백업한 지 일주일이 지나면 할 일·일정 탭 상단에 다시 저장하라는 안내가 떠요.
  • 불러오기를 하면 지금 내용에 백업 내용이 합쳐져요. 같은 날짜의 할 일은 백업 쪽으로 바뀌고, 일정은 중복된 건 건너뛰어요.
  • PC를 바꾸거나 캐시를 지우기 전에 한 번 저장해두면 안전해요.

8. 함께 보면 좋은 문서

🎬 Playwright 자동화 세팅 가이드 반복적인 QA 작업(로그인, 지면 진입 등)을 자동으로 실행하는 방법. 관리자 권한 없이 설치하고, 녹화 기능으로 코딩 없이 스크립트를 만들 수 있어요.
⚠ 수정한 내용이 반영이 안 될 때

설정이 브라우저에 저장되어 있다 보니, 새 버전이 배포되거나 기본 문구가 바뀌어도 예전 설정이 그대로 보일 수 있어요. 이럴 땐 아래 순서로 해결하세요.

  1. 강력 새로고침 — Ctrl + F5 (Mac은 Cmd + Shift + R)
  2. 그래도 안 되면 섹션 설정 → 기본값 복원을 눌러 최신 기본 구성으로 되돌리기
  3. 그래도 안 되면 브라우저 캐시·사이트 데이터 삭제 후 재접속
    Chrome/Edge: 설정 → 개인정보 보호 → 인터넷 사용 기록 삭제 → 캐시된 이미지 및 파일 + 쿠키 및 기타 사이트 데이터

캐시를 지우면 내가 커스텀한 설정도 함께 초기화돼요. 공들여 바꾼 구성이 있다면 미리 파일로 내보내기로 백업해두세요.

제목

⚠ Android · iOS 둘 다 발생하면 각각 별도 이슈로 등록해야 해요.
앱·MW 모두 발생 → 서버 이슈일 수 있어요. 검색 / 상품상세 / 공통유닛 쪽을 함께 확인하세요.

발생 기기

소유자가 바뀌거나 기기·OS가 변경되면 여기서 고치세요. 적용하면 자동 저장돼서 다음에 열 때도 유지돼요. 팀 공유·백업은 상단의 파일로 내보내기로 하세요.

Description

섹션 설정

섹션 이름·안내문구를 바꾸거나 추가/삭제/순서 변경할 수 있어요. 적용하면 이 브라우저에 자동 저장돼서 다음에 열 때도 유지돼요. 팀 공유·백업용 파일이 필요하면 상단의 파일로 내보내기를 쓰세요.

이슈 확인

저장하면 다음에 열 때 버전이 자동으로 채워져요. 버전이 바뀌면 칸을 고친 뒤 다시 저장하면 돼요.
결과 옵션을 한 줄에 하나씩 적으세요 (예: Done, FAIL, Pass, 보류). 적용하면 자동 저장돼서 다음에도 유지돼요.
확인 내용 끝에 붙일 문구를 한 줄에 하나씩 적으세요. 적용하면 자동 저장돼서 다음에도 유지돼요.
MW·통합앱 등 여러 환경에서 확인했으면, 한 환경 입력 후 블록 추가 → 다음 환경을 이어서 작성하세요.
설날·추석처럼 해마다 바뀌는 공휴일이에요. YYYY-MM-DD | 이름 형식으로 한 줄씩 적으세요. 신정·삼일절 등 매년 같은 날짜는 자동으로 표시돼요.

할 일

입력한 할 일은 이 브라우저에 자동 저장돼요. 날짜를 클릭하면 그 날의 할 일을 볼 수 있어요.

내 데이터 백업

할 일·일정·연차는 이 브라우저 안에만 저장돼요. 브라우저 캐시(인터넷 사용 기록)를 지우거나 다른 PC에서 열면 내용이 보이지 않아요. 아래 버튼으로 백업 파일 하나만 받아두면 언제든 그대로 되돌릴 수 있어요.

받은 파일은 회사 구글 드라이브·원드라이브 등 동기화되는 폴더에 두면 PC가 바뀌어도 안전해요. 불러오기를 하면 지금 내용에 백업 내용이 합쳐져요(같은 날짜·일정은 백업 쪽으로 덮어써요).

일일보고

완료한 할 일 가져오기

할 일·일정 탭에서 보고 날짜와 같은 날에 체크(완료)한 할 일들을, 왼쪽에서 고른 항목의 상세 내용으로 한 번에 옮겨 적어줘요.

  • 틈틈이 할 일 탭에 기록해두면, 버튼 한 번으로 일일보고가 채워져요.
  • 기존에 적어둔 내용은 지워지지 않고 아래에 이어서 추가돼요.
  • 이슈 관련 항목으로 가져오면 건수도 자동 계산돼요.
  • 완료 표시하지 않은 할 일은 가져오지 않아요.
